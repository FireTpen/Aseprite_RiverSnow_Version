# Pixel Palette Lab

面向 2D 像素游戏资产的 Aseprite 调色板插件。它按“颜色用途”生成色阶，而不是只给一串无语义的色块。

## 已实现

- 灌木、树冠、水体、草地、土地五种快速预设。
- 可拖拽的色相环，以及色相、饱和度、主体明度滑杆。
- 8 个可编辑的语义色阶：极高光、高光、亮部、受光、主体、中阴影、深阴影、轮廓。
- 色块左键设置 Aseprite 前景色、右键设置背景色。
- 一键应用为当前精灵调色板。
- 导出带角色名称的 GPL 与 JSON，便于在 Aseprite 外继续查看颜色用途。

## 安装

使用同目录的 `pixel-palette-lab.aseprite-extension`：双击安装，或在 Aseprite 中打开 `编辑 > 首选项 > 扩展 > 添加扩展` 选择该文件。安装后重启 Aseprite，再从 `文件 > Scripts > 打开像素配色助手...` 打开。

## 用法建议

对灌木或树冠：先用主体铺形，再用中阴影刻体积，受光/亮部画上表面，极高光只用于少量闪点，最后用轮廓控制剪影。不要每个颜色都平均使用。

## 当前边界

Aseprite 的原生调色板栏并不能稳定显示每个颜色的名称，所以插件始终在自己的角色列表中展示名称；GPL/JSON 则保留这些名称，作为可携带的配色说明。
